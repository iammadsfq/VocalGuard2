⚠️ Catatan Metodologi & Interpretasi Deteksi Real-Time:
  • Deteksi Streaming Per-Chunk: Selama merekam mikrofon atau memutar stream audio, sistem mengekstraksi jendela geser (sliding window) 1.28 detik (20.480 sampel @ 16kHz → 128 frame LFCC) secara kontinu dan menampilkan status BONAFIDE (Asli) vs SPOOF (Fake) beserta skor logit mentah $s = \text{logit}_{\text{bona}} - \text{logit}_{\text{spoof}}$.
  • Penanganan Silence Shortcut (H6 — Müller dkk., 2021): Dilengkapi penjaga Voice Activity Detection (VAD) berbasis energi RMS agar segmen hening saat merekam ditandai sebagai SILENCE dan tidak memicu alarm palsu.
  • Perbandingan Langsung FP32 vs INT8 Saat Streaming: Di CPU tanpa AVX-512 VNNI (Intel i7-8665U), ONNX FP32 (~9 ms) lebih cepat dibanding ONNX Dynamic INT8 (~38 ms), meskipun INT8 menghemat 73% memori (576 KB) dengan paritas EER identik (0.59% vs 0.59%).
