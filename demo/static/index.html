Vocal-Guard — Per-Chunk CPU Inference & Latency Demo

Pipeline Proof-of-Concept: 60-dim LFCC (vocal_guard/features.py) → LCNN + MFM → ONNX Runtime CPU
Chunk: 1.28s (20,480 samp @ 16kHz → 128 frames) FP32: 2.08 MB | INT8: 0.56 MB (-73%)
⚠️ Batasan Klaim Ilmiah & Metodologi (Harap Dibaca):
  • Bukan Vonis Deepfake Dunia Nyata: Demo ini adalah proof-of-concept untuk memvalidasi eksekusi pipeline dan mengukur latensi inferensi CPU per potongan (chunk) 1.28 detik serta Real-Time Factor (RTF).
  • Skor Mentah (Tanpa Label REAL/FAKE): Skor ditampilkan sebagai selisih logit mentah $s = \text{logit}_{\text{bonafide}} - \text{logit}_{\text{spoof}}$ (nilai positif condong ke distribusi bonafide ASVspoof, nilai negatif condong ke distribusi spoof).
  • Distribusi & Panjang Input: Model M1 dilatih pada rekaman bersih ASVspoof 2019 LA berdurasi 4.0 detik (399 frame: 4.59% Pooled Eval EER pada A07–A19, 0.37% Dev EER pada A01–A06). Pada potongan 1.28 detik (128 frame), Dev EER terukur sebesar 1.33%, sedangkan input mikrofon langsung tetap berada di luar distribusi akustik pelatihan (out-of-domain).
  • Temuan Jujur FP32 vs INT8 di CPU Non-VNNI: Model ONNX FP32 dijadikan default karena dieksekusi langsung dengan instruksi vektor AVX2 FMA (~9–15 ms), sedangkan ONNX Dynamic INT8 (meskipun ukurannya 73% lebih kecil: 576 KB dan menjaga paritas EER 0.59% vs 0.59%) memerlukan komputasi dynamic quantization/dequantization per layer yang lebih lambat (~35–45 ms) pada CPU laptop tanpa instruksi AVX-512 VNNI.

2. Interpretasi Metrik & Ekspor Sesi

Setiap potongan audio berdurasi 1.28 detik diekstrak menjadi matriks LFCC (60 × 128) menggunakan fungsi Python yang identik dengan saat pelatihan:

Skor Mentah = logit_bonafide − logit_spoof
• Skor > 0 : Condong ke pola spektral bonafide ASVspoof
• Skor < 0 : Condong ke pola artefak spoof ASVspoof
• RTF = (Waktu Proses Detik) / 1.28 detik (Target ≪ 1.0)
